# Vietnam Travel

越南旅行手账，河内与岘港分目录管理。

- `/`：行程入口
- `/hanoi/`：2026年11月22–26日，河内／沙坝5天4晚，包含联网天气预报
- `/danang/`：2026年11月10–14日，岘港／会安／顺化5天4晚

## GitHub Pages
仓库名：`vietnam-travel`。将本文件夹内的文件及目录上传到仓库根目录。
在 Settings → Pages → Build and deployment 中选择 Deploy from a branch，分支 main，目录 / (root)，保存。
发布成功后访问 `https://shaniceestravel.github.io/vietnam-travel/`。
河内链接：`https://shaniceestravel.github.io/vietnam-travel/hanoi/`。
岘港链接：`https://shaniceestravel.github.io/vietnam-travel/danang/`。

无需安装依赖。公开版本不含原模板中的联系人姓名、电话、地址，联系事项请通过报名群确认。
